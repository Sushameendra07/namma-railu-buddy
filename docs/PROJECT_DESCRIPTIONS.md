## Resume (bullet points)

- Built **Namma Railu Buddy**, an Android (Kotlin) commuter app targeting South Western Railway stations (SBC, YPR, MYS, etc.).
- Integrated **Firebase Authentication** and **Realtime Database** (asia-southeast1) for live train status, platform pings, and user alarm sessions.
- Implemented **Fused Location** proximity alarms with notifications, vibration, and configurable trigger radius (1–50 km).
- Designed **XML + View Binding** UI with coach-sequence visualization, RecyclerView train/alert lists, and bottom-navigation architecture.
- Authored demo seed data, test matrix, and release-ready Gradle builds (`assembleDebug` / `assembleRelease`).

## Internship submission (paragraph)

Namma Railu Buddy is a Kotlin-based Android railway assistance application designed to improve the daily commuting experience for users in Karnataka and the South Western Railway network. The application integrates Firebase Authentication, Firebase Realtime Database for station and train data, crowd-sourced platform verification with vote counts, destination proximity alarms using device location, searchable train listings, delay and platform-change alerts, and Google Maps support within a Material Design interface. The project demonstrates fragment-based navigation, View Binding, permission handling for location and notifications, Firebase transactions, and structured demo/testing documentation suitable for academic evaluation.

## Elevator pitch (30 seconds)

*Namma Railu Buddy is our Kannada-inspired Android app for Karnataka train travelers. Users log in with Firebase, pick their station and train, see live status and coach layout, help each other confirm platforms, and set an alarm that fires when they're within a few kilometers of their destination. It’s built in Kotlin with Firebase and Google Maps — built for real commuting problems, not just a tutorial clone.*
